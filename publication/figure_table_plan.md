## Artifact-only production protocol

1. Read only the exact serialized CSV/JSON/Markdown sources named above.
2. Verify their SHA-256 values against the frozen stage manifests before plotting.
3. Plot only stored point estimates, intervals, verdicts, counts or registry definitions; do not reconstruct them from NPZ payloads.
4. Record every panel-to-source mapping and the exact source hash in a figure provenance table.
5. Treat cosmetic choices, axis ordering and annotation as publication transforms; never use them to change a gate or hide a failed/unevaluable status.
6. Stop if a requested visual requires a new metric, regrouping, bootstrap, target read or scientific computation.
